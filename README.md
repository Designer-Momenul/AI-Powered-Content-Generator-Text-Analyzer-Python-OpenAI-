# AI-Powered Full-Stack Integration Project

A professional, responsive full-stack web application featuring a live AI chat integration assistant. The project is designed with a modern frontend interface and connected to a Python-based backend to process intelligent user interactions.

## 🚀 Features

- **Responsive UI:** Modern, clean, and mobile-friendly layouts for the landing page, About Us, and Services sections.
- **AI Chat Agent Widget:** A floating interactive chat bubble that connects users directly to an intelligent assistant.
- **Python Backend:** A lightweight, secure API implementation to manage AI request processing and connectivity.
- **Production Ready:** Optimized configurations for deployment on standard domain and hosting environments.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Flexbox/Grid layout fixes applied), JavaScript (ES6+)
- **Backend:** Python, Web API Framework
- **Version Control & Deployment:** Git, GitHub

## 📂 Project Structure

```text
├── index.html          # Main products landing page
├── css/
│   └── style.css       # Responsive styling (fixed service overlay issues)
├── js/
│   └── main.js         # Frontend interactive chat bubble logic
├── app.py              # Python API for AI engine integration
└── README.md           # Project documentation
```

## ⚙️ Setup and Installation

### 1. Frontend Setup
Open `index.html` directly in your browser, or serve it using a local live server.

### 2. Backend Setup
1. Navigate to the project directory.
2. Install the necessary dependencies for the Python API.
3. Run the development server:
   ```bash
   python app.py
   ```

### 3. Deployment
- Upload frontend assets (`index.html`, `css/`, `js/`) to your public hosting directory (e.g., `public_html`).
- Configure your domain to reverse-proxy backend AI requests to your hosted Python service.
